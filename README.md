# 校园生活模拟器（独立 iOS PWA）

独立实现的 iPhone 网页 App，参考校园事务产品形态，不复制 Today-Campus 源码、品牌素材或官方身份。

## 功能
- 本地请假记录：新建、编辑、删除
- 本地个人资料
- 签到演示（不读取定位、不验证身份）
- DEMO 二维码占位（不可扫描）
- 课程表、校园推荐、邀请分享
- 主题颜色切换、本地 JSON 备份
- 全部功能免费，无 VIP、会员、订阅或付费墙

## iPhone 安装
1. 使用 Safari 打开 GitHub Pages 网站。
2. 点击「分享」→「添加到主屏幕」→「添加」。
3. 从主屏幕图标打开。

## 边界
非官方演示程序，不连接学校服务器，不提供真实审批、考勤、身份核验、支付或有效二维码。数据仅保存在当前设备。请勿填写真实密码、身份证号等敏感信息。
